# University Work — Jasper Middleton

A portfolio of coursework, lab exercises and projects from my undergraduate studies at **Northeastern University London**.

This repository is here so recruiters and hiring managers can see how I work: how I approach problems, how I structure code and analysis, and how my skills develop over the course of my degree. It is organised by module and is updated as I complete new work.
