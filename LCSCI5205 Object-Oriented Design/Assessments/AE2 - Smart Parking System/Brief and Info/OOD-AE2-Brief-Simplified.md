# Object-Oriented Design AE2: Assessment Brief (Simplified)

## Assessment Task

Using object-oriented design, develop an application that simulates a smart parking management system. The application should demonstrate your understanding and implementation of Singleton and Observer design patterns. Additionally, you are required to produce a UML class diagram of the system

## Object Oriented Design Project and Object Oriented Coding Exercise

In this part of the assessment exercise, you are asked to develop an application using object-oriented programming to simulate a smart parking management system based on your previous UML diagram. The objective is to maximize code reuse and demonstrate your understanding and implementation of design patterns and object-oriented principles.

You will be required to document your code and provide a report detailing how and where your code demonstrates the following features:

- Singleton Design Pattern
- Observer Design Pattern
- Objects
- Classes
- Encapsulation
- Constructors
- Inheritance
- Polymorphism

The application should include:

- Management of various types of parking spots such as regular, disabled, and electric vehicle charging.
- Real-time monitoring of the occupancy status of these parking spaces.
- Notification mechanisms for significant events (e.g., parking space availability, unauthorised parking).
- Extensibility to add new types of parking spots or additional features.

Your program must use standard data structures (e.g., lists, hash tables, sets) and handle standard data types (e.g., strings, booleans, integers, floating points).

Do not worry about the user interface. Your code must be well documented to clearly show the implementation of object-oriented principles and design patterns. Discuss with your lecturer any other types of programming applications or ideas for software applications you wish to explore.
