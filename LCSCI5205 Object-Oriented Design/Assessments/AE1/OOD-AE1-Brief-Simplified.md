Assessment Task
Object Oriented Design Project and Object Oriented
Coding Exercise
In this part of the assessment exercise, you are asked to develop an application
using object-oriented programming to maximise code reuse based on your previous
UML diagram.
You will be required to document your code and provide a report detailing how and
where your code demonstrates the following features:
● Objects
● Classes
● Encapsulation
● Constructors
● Inheritance
● Polymorphism

For the purpose of this exercise do not worry about the user interface. Your code
must be well documented. The program must use standard data structures for
example (lists, hash tables, sets, etc.; strings, booleans, integers, floating points)
