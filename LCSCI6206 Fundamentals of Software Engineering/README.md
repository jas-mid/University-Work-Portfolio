## Module overview

> What happens to good code when a second developer joins the project, or a thousand more users show up? That's the animating question of this course — because the practices that make software work on your laptop are rarely the ones that make it survive contact with teams, scale, and time, and learning to see that gap is what separates a programmer from a software engineer. Across the term, you'll design, refactor and test real software as part of a team, using the same patterns, architectural trade-offs, and deployment pipelines that power products like Twitter and Instagram — not as an exercise in following rules, but as practice in making the judgement calls that decide whether software lasts.
>
> — *Official module descriptor*
